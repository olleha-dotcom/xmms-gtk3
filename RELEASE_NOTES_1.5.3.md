## XMMS GTK3 1.5.3

Maintenance release for the GTK3 port.

### Changes
- Hardened config file loading and saving diagnostics.
- Replaced several unsafe fixed-buffer string writes with bounded GLib helpers.
- Improved robustness around playlist save failures and config write failures.
- Kept the GTK3 port/package version aligned for the 1.5.3 release.

### Package
- Ubuntu 24.04+ `.deb` package: `xmms-gtk3_1.5.3-1ubuntu24.04_amd64.deb`
